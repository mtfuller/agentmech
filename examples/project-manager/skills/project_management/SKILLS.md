# Project Management Skills

## Project Planning
- Define clear project goals and objectives
- Identify all project stakeholders and their expectations
- Create detailed work breakdown structure (WBS)
- Establish realistic timelines with milestones
- Allocate resources effectively across tasks

## Scope Management
- Define project scope clearly and get stakeholder approval
- Document all requirements and acceptance criteria
- Manage scope creep by evaluating change requests
- Maintain a requirements traceability matrix
- Conduct regular scope reviews with stakeholders

## Task Prioritization
- Use MoSCoW method (Must have, Should have, Could have, Won't have)
- Consider task dependencies and critical path
- Balance urgent vs. important tasks
- Align priorities with business value
- Re-evaluate priorities regularly as project evolves
